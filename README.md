# Своим ходом

Личное приложение для тех, кто путешествует своим ходом, без туроператора: билеты, брони, события, визы, страховки, маршруты и документы в одном месте.

Приложение: https://anna1986.github.io/SUP/
Работает на телефоне и компьютере, открывается без интернета, можно установить на главный экран.

## Что умеет

- **Поездки**: текущая, предстоящие и прошедшие, с отсчётом дней до начала
- **Папки внутри поездки**: авиабилеты, поезда и автобусы, жильё, аренда авто, экскурсии и билеты, визы, страховки, маршруты, другое
- **План по дням**: автоматически собирается из броней (вылет, прилёт, заселение, выезд), подсвечивает ближайшее событие
- **Файлы**: к любой записи можно прикрепить PDF, скриншот или фото, а потом открыть, сохранить или переслать
- **Мои документы**: паспорта, права и полисы со сроками действия; если загранпаспорт истекает раньше чем через 6 месяцев после поездки, приложение предупредит
- **Резервная копия**: экспорт и импорт всех данных вместе с файлами
- **Офлайн**: после первого открытия приложение работает без интернета
- **Синхронизация**: после входа по почте и паролю данные и файлы одинаковые на телефоне и компьютере

## Где хранятся данные

На каждом устройстве лежит полная копия в браузере (IndexedDB), поэтому приложение работает офлайн. После входа изменения отправляются в Supabase (проект `travel-helper`, регион Франкфурт):

- таблица `records`: поездки, записи, документы и описания файлов (JSON), с пометкой удаления
- приватное хранилище `files`: сами файлы, лежат по пути `<user_id>/<attachment_id>`
- правила доступа (RLS) пускают пользователя только к его собственным записям и файлам

Как устроена синхронизация (`src/sync.ts`): каждое локальное изменение попадает в очередь исходящих, при появлении сети очередь отправляется, затем забираются изменения с сервера, появившиеся после прошлой синхронизации. Если у записи есть неотправленное локальное изменение, побеждает локальное.

## Структура

```
src/
  db.ts            модель данных и хранилище
  trip.ts          план по дням, сроки, предупреждения
  backup.ts        резервная копия
  sync.ts          синхронизация с Supabase
  supabase.ts      подключение к Supabase
  pages/           экраны
  components/      общие элементы и вложения
sw-template.js     service worker для работы офлайн
public/            иконки и манифест
docs/              видение и решения
```
