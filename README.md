# СУП — система управления проектами

Личный инструмент индивидуального проектного менеджера: все проекты, задачи, сроки, исполнители и прогресс в одном месте.

## Статус

🟢 В разработке. Готов раздел «Проекты».

Приложение: https://anna1986.github.io/SUP/ (работает на телефоне и компьютере, можно добавить на главный экран как приложение).

## Планируемые возможности (MVP)

- **Проекты** — создание проекта, описание, сроки, заказчик, участники
- **Задачи** — название, описание, исполнитель, срок, приоритет, статус
- **Канбан-доска** — колонки «Нужно сделать → В работе → На проверке → Готово»
- **Контакты** — исполнители и заказчики, с которыми работает менеджер
- **Заметки** к задачам
- **Дашборд** — прогресс по проектам, просроченные задачи
- **Резервная копия** — экспорт и импорт данных в файл

## Дальше (после MVP)

## Структура репозитория

```
src/             код приложения (React + TypeScript)
  pages/         экраны
  db.ts          хранилище данных в браузере (IndexedDB)
public/          иконки и манифест для установки на телефон
docs/            документация: видение, решения
.github/         автоматическая публикация на GitHub Pages
```

## Запуск локально

```
npm install
npm run dev
```

Данные хранятся в браузере на устройстве. На телефоне и на компьютере данные пока раздельные.
