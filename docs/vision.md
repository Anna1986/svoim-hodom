# Видение проекта

## Зачем

В поездке всё нужное разбросано по разным местам: билеты в Aviasales и почте, брони в Booking, ваучеры в скриншотах, визы и паспорта в галерее, маршруты в заметках. Приложение собирает это в одно место: открыл поездку и сразу видишь, когда вылет, где заселение и куда идти завтра.

## Для кого

Для путешественника, который сам организует свои поездки. Сейчас пользуется только автор, без входа по логину.

## Основные идеи

- **Поездка** содержит папки по типам записей
- **Запись** — это бронь, билет, ваучер, виза или маршрут: даты, время, места, номер брони, ссылка, заметки и файлы
- **План по дням** строится автоматически из записей
- **Мои документы** хранятся отдельно от поездок и используются в каждой
- Время указывается местное, как в билете, без пересчёта часовых поясов
- Приложение работает офлайн, потому что в поездке интернет бывает не всегда

## Стек

- React + TypeScript + Vite
- IndexedDB (через Dexie): данные и файлы хранятся на устройстве
- Service worker для работы офлайн
- GitHub Pages для хостинга, публикация автоматическая

## Идеи на будущее

- Вход и синхронизация между телефоном и компьютером
- Добавление брони пересылкой письма или загрузкой PDF с автоматическим распознаванием
- Чек-лист вещей для поездки
- Бюджет и расходы поездки
- Карта с точками маршрута
- Совместные поездки
