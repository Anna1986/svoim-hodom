# Видение проекта

## Зачем

Нужен простой и понятный инструмент, чтобы видеть все проекты и задачи в одном месте: кто что делает, к какому сроку и что горит.

## Для кого

_Уточнить:_ личное использование / небольшая команда / компания.

## Открытые вопросы

1. Кто пользователи и сколько их?
2. Нужен ли вход по логину/паролю и разграничение прав?
3. Где будет работать: только в браузере или нужен ещё мобильный вариант?
4. Технологии: готовый стек (например, Python + Django или JavaScript + Next.js) или есть предпочтения?
5. Где хранить и запускать: бесплатный хостинг, свой сервер?
