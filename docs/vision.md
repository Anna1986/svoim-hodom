# Видение проекта

## Зачем

Нужен простой и понятный инструмент, чтобы видеть все проекты и задачи в одном месте: кто что делает, к какому сроку и что горит.

## Для кого

Индивидуальные проектные менеджеры, которые сами ведут свои проекты. Система — личный рабочий инструмент менеджера, а не общая платформа для команды.

На первом этапе пользователь один (автор проекта). Входа по логину и паролю пока нет, он появится позже.

Исполнители задач в системе — это просто имена/контакты, которые менеджер записывает сам. Сами исполнители в систему не заходят.

## Предлагаемый стек (на согласовании)

- **React + TypeScript + Vite** — веб-приложение в браузере
- **Хранение данных в браузере (IndexedDB)** + экспорт/импорт в файл для резервной копии
- **GitHub Pages** — бесплатный хостинг, сайт обновляется автоматически при каждом изменении в репозитории

Почему так: не нужен сервер и база данных, всё бесплатно и запускается сразу. Когда понадобится вход и доступ с разных устройств, добавим облачное хранилище (например, Supabase) без переписывания интерфейса.
